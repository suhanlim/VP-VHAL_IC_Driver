# VNF9Q20F 드라이버 사양서

## 1. 동작 프로세스

| 단계 | 모드 | 설명 | 비고 |
|------|------|------|------|
| 1 | Sleep mode | 표준제어기 전원 투입 후 자동 진입 | |
| 2 | Fail-safe mode | STDBY_NOT을 HIGH로 제어하여 Fail-safe mode 진입 | |
| 3 | Fail-safe mode | 차량 IO 신호 DB 기반 레지스터 Write | 레지스터 초기 설정 및 차량 IO 신호 DB 기준 레지스터 설정 방법 참조 |
| 4 | Fail-safe mode | 모든 채널 진단 및 리포트 출력 | [초기 진단](#초기-진단-4단계) 참조 |
| 5 | Normal mode | SPI를 통한 Normal mode 진입 | 1. UNLOCK=1<br>2. EN=1 AND GOSTBY=0 |

| 7 | Normal mode | PWM clock 동기화 | PWM SYNC=1 |
| 8 | Normal mode | 앱SW에 의한 할당 채널 활성화 | |

| 10 | Normal mode | 앱SW에 의한 할당 채널 비활성화 | |
| 11 | Pre-standby mode | SPI를 통한 Pre-standby mode 진입 | 1. UNLOCK=1 AND EN=1<br>2. EN=0 AND GOSTBY=1 |
| 12 | Standby mode | STDBY_NOT을 LOW로 제어하여 Standby mode 진입 | |
| 13 | Standby mode | 표준제어기 노멀 모드 진입 | 도어 핸들 스위치 등 특정 신호 입력 시 |
| 14 | Fail-safe mode | STDBY_NOT을 HIGH로 제어하여 Fail-safe mode 진입 | |
| 15 | - | 4번부터 반복 | |

### 초기 진단 (4단계)

1. **ADC 진단**
   - `ADCLSRx` 읽기: 값이 81 근처인지 진단 (71~91 사이면 정상)
   - `ADCMSRx` 읽기: 값이 325 근처인지 진단 (293~357 사이면 정상)
   - `ADCHSRx` 읽기: 값이 890 근처인지 진단 (819~961 사이면 정상)

2. **I2T 진단**
   - `ITSTx`가 `111b`인지 진단

3. **각 채널의 Open/Short 진단**
   - [Open/Short 진단 프로세스](#41-openshort-진단-프로세스) 참조

### 4.2 CCM 모드 프로세스

#### a. 동작 순서

| 동작 순서 | 상세 프로세스 | 비고 |
|-----------|---------------|------|
| 1 | 신호DB의 PWM 파라미터가 `PWM_C`이면 해당 신호는 출력 ON 시 CCM 모드로 동작해야 함 | |
| 2 | 앱SW에 의해 해당 채널 ON 동작 시 `CAPCRx`와 `SOCRx`를 동시에 1로 설정 | CCM모드 시작과 출력 ON 시점 동기화 |
| 3 | MCU 동작 주기(5ms)마다:<br>- `VDSHSRx=1`이면 신호DB의 CT 파라미터 시간에 도달했는지 비교하여 도달할때까지 반복<br>- `VDSHSRx=0`이면 `EXIT_CAPCRx=1`로 설정하여 CCM 모드를 종료하고 CCM 모드가 몇ms만에 수동 종료됐는지 콘솔 로그 출력 | 수동 종료 시 CCM 모드 유지 시간 출력 (MCU 동작 주기 시간을 CCM 모드 유지 시간 단위로 할 것) |
| 4 | CCM 모드 유지 시간이 신호DB의 CT 파라미터 설정값에 도달하면 `EXIT_CAPCRx=1`로 설정하고 CT 파라미터 설정값과 동일하게 CCM 모드가 유지되었음을 콘솔 로그 출력 | 종료 시 CCM 모드 유지 시간과 `VDSHSRx` 값을 같이 출력 (MCU 동작 주기 시간을 CCM 모드 유지 시간 단위로 할 것) |
